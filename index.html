Conhecendo o CSS

Oque é CSS

CSS significa Cascading Style Sheets, ou, em português, Folhas de estilo em cascata.

É a linguagem responsável por definir a apresentaçãoi visual de um documento HTML.

Como trabalhar com o CSS?

Existe três formas clássicas de colocar o CSS em um arquivo HTML:

  • css inline
  • css interno
  • css externo

Conhecendo o CSS Inline

Nessa abordagem, o CSS é colocado diretamente no elemento HTML através de um atributo chamado de style

Aplicando o atributo no elemento.

Conhecendo o CSS Interno

Nessa aborda, o css é colocado dentro de uma tag 

 < style >

Conhecendo o CSS Externo

Nessa abordagem, o CSS é aplicado em uma folha de estilos externa, conectada por um elemento de < link > dentro do < head > do documento.
